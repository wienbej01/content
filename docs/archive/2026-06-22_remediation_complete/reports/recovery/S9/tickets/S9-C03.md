## Observable outcome
After a (mocked/test-mode) TTS run, the production has a `cost_events` row for the TTS operation carrying provider `elevenlabs`, a USD amount, and a link to the production — so spend is auditable. Observable by: a unit test that runs the TTS path with a deterministic fixture (YT_TEST_MODE, no real call) and asserts a `cost_events` row exists with the expected estimated cost.

## Evidence and rationale
- **Observed current behavior:** `invoke_tts` made a real ~$0.30 ElevenLabs call (S9) but wrote no `cost_events` row; the ~$0.90 spent is not in the ledger.
- **Supporting paths:**
  - `scripts/produce_db.py:190-251` — `invoke_tts`: instantiates `paid_adapters.ElevenLabsAdapter` directly (`:226`), calls `submit` (`:227`), then `record_tts_artifact` (`:241`). **No `record_actual_cost` / `cost_events`.**
  - `scripts/paid_adapters.py:88-131` — `ElevenLabsAdapter`: `estimate_cost` (`:96-100`, $0.30/1000 chars) exists; `submit` returns `{audio_path, audio_size_bytes}` — **no cost field** in the response.
  - `scripts/provider_adapter.py:100-128` — `record_actual_cost(provider_job_id, actual_usd)` INSERTs into `cost_events` but **requires a `provider_jobs` row** (TTS has none — TTS uses the adapter directly, not `submit_provider_job`).
  - `scripts/media_service.py:254` and `scripts/tts_service.py:387,408` — existing `cost_events` INSERT/SUM helpers (the generation path records cost; mirror it).
- **Confirmed root cause:** TTS bypasses the provider-jobs/cost pipeline; no cost row is written.
- **Why necessary:** spend against the $5 cap must be auditable; the user requires it.

## Scope
- **Expected change areas:** `invoke_tts` records cost after a real (non-test-mode) call. Because TTS has no `provider_jobs` row, either (a) write `cost_events` directly via the `tts_service` helper, or (b) create a `provider_jobs` row for TTS and reuse `record_actual_cost`. Prefer the smaller change; record **estimated** cost from `estimate_cost` (actuals are unavailable inline — document this).
- **Permitted inspection areas:** `tts_service.py` cost helpers, `media_service.py:254`, `migrate_legacy.py:219` (SUM query).
- **Protected:** the YT_TEST_MODE refusal (`:217`); `record_tts_artifact` behavior.
- **Exclusions:** do not change ElevenLabs adapter HTTP logic; do not make paid calls in tests.
- **Discovery:** confirm the `cost_events` schema (`id, production_id, provider_job_id NULLABLE?, provider, operation, actual_usd, currency, created_at`) and whether `provider_job_id` is nullable (TTS has no job id). If not nullable, use option (b) or make the column nullable via additive migration.
