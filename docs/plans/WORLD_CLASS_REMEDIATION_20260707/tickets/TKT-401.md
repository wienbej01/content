## Observable outcome

`scripts/citation_verify.py` with:
- `fetch_and_extract(url) -> str` (HTML→text via readability-lxml, cached).
- `extract_entities(text) -> dict` (deterministic NER heuristic).
- `verify_claim(claim_text, source_text) -> float` (overlap score).
- `CITATION_CONFIDENCE_THRESHOLD` (default 0.6).

Each `key_claim` verified after research synthesis; results recorded in brief as `citation_verification`.

Behind config flag `CITATION_VERIFY_MODE = off|on`. Default `off`. Test mode uses TKT-003 fixtures.
