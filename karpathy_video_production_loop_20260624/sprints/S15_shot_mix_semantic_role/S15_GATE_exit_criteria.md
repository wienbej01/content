# S15 Exit Criteria

The sprint may close only when every sprint success criterion is satisfied:

- [ ] Shorts require minimum shot mix.
- [ ] Labels verified against rendered content.
- [ ] B-roll visually distinct from hero.
- [ ] Graphics are explanatory, not title cards.
- [ ] Assembly blocks if shot plan violates contract.

## Required reports

- Each ticket has engineering/audit/validation reports.
- Sprint summary exists.
- Loop state updated.
- No unresolved BLOCKER/MAJOR items.

## Exit decision

The Steering Committee must write:

`reports/karpathy_loop/s15/sprint_summary.md`

with:

- PASS/FAIL/BLOCKED
- evidence paths
- tests run
- known residual risks
- next sprint readiness
