# S18 Exit Criteria

The sprint may close only when every sprint success criterion is satisfied:

- [ ] Every beat has viewer_need and visual_thesis.
- [ ] Every visual role justified.
- [ ] Abstract claims require graphics or concrete examples.
- [ ] B-roll is not generic filler unless explicitly emotional_reset.
- [ ] Shot plan validates before render.

## Required reports

- Each ticket has engineering/audit/validation reports.
- Sprint summary exists.
- Loop state updated.
- No unresolved BLOCKER/MAJOR items.

## Exit decision

The Steering Committee must write:

`reports/karpathy_loop/s18/sprint_summary.md`

with:

- PASS/FAIL/BLOCKED
- evidence paths
- tests run
- known residual risks
- next sprint readiness
