# S20 Exit Criteria

The sprint may close only when every sprint success criterion is satisfied:

- [ ] Provider capabilities explicit.
- [ ] Hero providers require diagnostic/sync evidence.
- [ ] B-roll providers declare resolution/duration/aspect/cost/prompt features.
- [ ] Provider selection logged.
- [ ] Fallback explicit only.

## Required reports

- Each ticket has engineering/audit/validation reports.
- Sprint summary exists.
- Loop state updated.
- No unresolved BLOCKER/MAJOR items.

## Exit decision

The Steering Committee must write:

`reports/karpathy_loop/s20/sprint_summary.md`

with:

- PASS/FAIL/BLOCKED
- evidence paths
- tests run
- known residual risks
- next sprint readiness
