# S17 Exit Criteria

The sprint may close only when every sprint success criterion is satisfied:

- [ ] Candidate sets exist.
- [ ] Each candidate scored.
- [ ] Best candidate selected with reason.
- [ ] Rejected candidates logged.
- [ ] All-fail candidate group blocks assembly.

## Required reports

- Each ticket has engineering/audit/validation reports.
- Sprint summary exists.
- Loop state updated.
- No unresolved BLOCKER/MAJOR items.

## Exit decision

The Steering Committee must write:

`reports/karpathy_loop/s17/sprint_summary.md`

with:

- PASS/FAIL/BLOCKED
- evidence paths
- tests run
- known residual risks
- next sprint readiness
