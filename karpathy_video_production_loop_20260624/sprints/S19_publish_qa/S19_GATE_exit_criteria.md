# S19 Exit Criteria

The sprint may close only when every sprint success criterion is satisfied:

- [ ] Publish-grade 16:9 requires 1920x1080 unless explicit profile override.
- [ ] Dry-run/test artifacts cannot be publish-grade.
- [ ] Audio/video duration tolerance <=100ms.
- [ ] Black/blank/static gates enforced.
- [ ] Per-hero SyncNet, visual-role QA, graphic QA required.
- [ ] Gate B package truthful.

## Required reports

- Each ticket has engineering/audit/validation reports.
- Sprint summary exists.
- Loop state updated.
- No unresolved BLOCKER/MAJOR items.

## Exit decision

The Steering Committee must write:

`reports/karpathy_loop/s19/sprint_summary.md`

with:

- PASS/FAIL/BLOCKED
- evidence paths
- tests run
- known residual risks
- next sprint readiness
