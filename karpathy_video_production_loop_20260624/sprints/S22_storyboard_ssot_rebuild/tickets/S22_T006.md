# S22_T006 - Build Sonnet 5 storyboard wrapper plan

## Objective

Implement the wrapper path that assembles the approved script context packet, invokes Sonnet 5 via Kilo, parses the canonical storyboard JSON, and records authoring metadata without letting Python create creative choices.

## Primary agent

Storyboard Architect

## Supporting agents

- Prompt Guardrail Engineer
- Software Engineer
- Software Auditor
- Software Validator

## Recommended model

`deepseek-v4-pro`

## Context files to load first

- `S22_MODEL_ROUTING.md`
- `S22_PROMPT_GUARDRAILS.md`
- `S22_CODING_RULES.md`
- `scripts/direct_storyboard.py`
- `scripts/llm_call.py`
- `scripts/produce_db.py`
- `scripts/authoring_service.py`
- `configs/llm_models.yaml`

## Likely implementation targets

- `scripts/direct_storyboard.py` or new small module under `scripts/`
- `scripts/produce_db.py` storyboard invoker
- `tests/test_sonnet_storyboard_wrapper.py`
- `reports/karpathy_loop/s22/S22_T006/`

## Explicit non-goals

- Do not run live Sonnet in tests.
- Do not implement validation rules from later tickets.
- Do not implement DB schema widening.
- Do not create Python fallback storyboard content.

## Required behavior

Wrapper must:

- Read approved script from DB or explicit input.
- Load source/context packet.
- Use `storyboard_director_sonnet5`.
- Require strict JSON.
- Preserve exact narration text.
- Store authoring profile/model/raw response metadata.
- Fail if output is not Sonnet-authored.
- Fail if output is empty or unparseable.
- Fail if Python fallback would be needed.

## Detailed tests

Required tests:

1. Stubbed Sonnet response returns canonical storyboard.
2. Wrapper passes profile `storyboard_director_sonnet5`.
3. Non-Sonnet response metadata fails.
4. Empty response fails.
5. Invalid JSON fails.
6. Script narration mutation fails or is handed to validator as blocking.
7. Python fallback function is never called; assert no deterministic creative assignment branch.
8. Dry-run emits prompt size/model without calling Kilo.

Required commands:

```bash
python3 -m pytest tests/test_sonnet_storyboard_wrapper.py -q
python3 -m pytest tests/test_llm_call.py -q
```

## Pass gates

- Wrapper can be tested with stubbed LLM.
- No live LLM needed in default tests.
- No Python creative fallback exists.
- Authoring metadata is captured.

## Audit checklist

- Inspect wrapper branches for fallback logic.
- Confirm only Sonnet profile is used.
- Confirm context packet includes approved script and bibles.

## Validation checklist

- Run focused tests.
- Run dry-run command.
- Inspect evidence JSON for model metadata.

## Done definition

Done only when Sonnet wrapper behavior is implemented and the no-Python-creative boundary is proven.
