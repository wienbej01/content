## Required behavior

Projection must derive:

- beat-level `shot_type`
- `asset_type`
- `model`
- `prompt_class`
- `visual_brief`
- `visual_intent`
- `graphic`
- `graphics`
- `reference_required`
- `text_policy`

Every projected field must include traceability to canonical `shot_id` and/or `overlay_id`.

## Detailed tests

Required tests:

1. Canonical shot projects to expected legacy beat fields.
2. Canonical overlay projects to both `graphic` and `graphics` compatibility shape if required by existing consumers.
3. Projection preserves shot/overlay IDs.
4. Projection fails if canonical shot is missing semantic source fields.
5. Projection output passes current compiler minimum fields.
6. Projection output passes current production storyboard minimum fields.
7. Projection never reads raw script `visual_brief`.

Required commands:

```bash
python3 -m pytest tests/test_storyboard_projection.py -q
python3 -m pytest tests/test_reconcile_storyboard.py tests/test_production_storyboard_schema.py -q
```

## Pass gates

- Compatibility is deterministic.
- Projection is traceable.
- No creative fields are invented by Python.
- `graphic`/`graphics` mismatch is resolved.
