# S22_T015 - Compile overlay plan from canonical overlays

## Objective

Create a deterministic overlay plan from Sonnet-authored canonical `overlays[]`, with timing, safe zones, semantic purpose, source refs, style tokens, and render instructions.

## Primary agent

Overlay Timeline Engineer

## Supporting agents

- Software Engineer
- Claim Compliance Auditor
- Software Auditor
- Software Validator

## Recommended model

`deepseek-v4-flash`

- `S22_STRUCTURAL_FRAMEWORK.md`
- `S22_PROMPT_GUARDRAILS.md`
- `scripts/render_graphics.py`
- `schemas/graphic_template.schema.json`
- `tests/test_render_graphics.py`
- `tests/test_graphic_schema.py`

## Likely implementation targets

- `schemas/overlay_plan.schema.json`

## Explicit non-goals

- Do not render overlays yet.
- Do not alter assembly.
- Do not call LLMs.

## Required behavior

Overlay compiler must emit:

- `overlay_job_id`
- `overlay_id`
- `shot_id`
- `segment_id`
- `text`
- `semantic_purpose`
- `source_ref`
- `start_time_offset_sec`
- `end_time_offset_sec`
- `position`
- `safe_for_9x16`
- `style_token`
- `animation`
- `render_method`
- `qa_rules`

## Detailed tests

Required tests:

1. Valid canonical overlay compiles to overlay job.
2. Overlay without semantic purpose fails.
3. Overlay with source label and missing source ref fails.
4. Text beyond max chars fails.
5. Unsafe 9:16 position fails.
6. Unknown style token fails.
7. Overlay timing outside shot duration fails.
8. Standalone graphic without justification fails.

Required commands:

```bash
python3 -m pytest tests/test_overlay_plan.py tests/test_graphic_schema.py -q
```

## Pass gates

- Overlay plan is deterministic.
- Every job maps to canonical overlay ID.
- Source labels are claim/source grounded.
- No generated-video text delegation.

## Audit checklist

- Confirm overlay jobs do not create creative text.
- Confirm safe-zone validation exists.
- Confirm source refs are enforced.

## Validation checklist

- Run focused tests.
- Inspect overlay plan fixture.

## Done definition

Done when canonical overlays can become deterministic render jobs.
