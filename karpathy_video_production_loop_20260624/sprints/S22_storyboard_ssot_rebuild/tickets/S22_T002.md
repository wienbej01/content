# S22_T002 - Add Sonnet 5 Kilo profile verification and no-fallback guard

## Objective

Add a runtime model-verification plan and implementation for a `storyboard_director_sonnet5` profile. Storyboard generation, repair, and creative review must use Sonnet 5 through Kilo or block. No fallback is allowed.

## Primary agent

Storyboard Architect

## Supporting agents

- Prompt Guardrail Engineer
- Software Engineer
- Software Auditor
- Software Validator

## Recommended model

`deepseek-v4-pro`

## Explicit non-goals

- Do not run a live storyboard generation.
- Do not make a real Sonnet call in default tests.
- Do not change non-storyboard model profiles unless required for authority enforcement.
- Do not replace Kilo integration wholesale.

## Required behavior

- Add `storyboard_director_sonnet5`.
- Add or document the exact Kilo model id after verification.
- Add an availability check that can be run in dry-run/static mode.
- Creative storyboard tasks must reject any profile that is not Sonnet 5.
- If the model is unavailable, error must be `BLOCKED_SONNET5_UNAVAILABLE`.
- If a caller requests fallback to another model, error must be `BLOCKED_CREATIVE_FALLBACK_FORBIDDEN`.

## Detailed tests

Required tests:

1. `test_storyboard_generation_requires_sonnet5_profile`
   - Given task `storyboard_generation` and `auto_utility`, `llm_call` fails.
2. `test_storyboard_repair_requires_sonnet5_profile`
   - Given task `storyboard_repair` and non-Sonnet profile, fail.
3. `test_storyboard_creative_review_requires_sonnet5_profile`
   - Given task `storyboard_creative_review` and non-Sonnet profile, fail.
4. `test_sonnet5_unavailable_blocks_no_fallback`
   - Mock Kilo model list without Sonnet 5; assert `BLOCKED_SONNET5_UNAVAILABLE`.
5. `test_no_deepseek_fallback_for_storyboard_authoring`
   - Mock failure and assert no call is attempted with DeepSeek.
6. `test_dry_run_reports_profile_model_without_calling_kilo`
   - `--dry-run` must not call subprocess.

Required command examples:

```bash
python3 -m pytest tests/test_llm_call.py -q
python3 scripts/llm_call.py --task storyboard_generation --model-profile storyboard_director_sonnet5 --prompt '{}' --dry-run
```

## Pass gates

- Profile exists.
- Runtime check blocks unavailable Sonnet 5.
- No silent fallback exists.
- Default tests stub Kilo and do not require live auth.
- Report states the verified model id or the blocker.

## Audit checklist

- Inspect all model-routing branches.
- Confirm no fallback path to DeepSeek/auto for storyboard authoring.
- Confirm error names are exact.
- Confirm tests mock subprocess rather than calling live Kilo.

## Validation checklist

- Run focused tests.
- Run a dry-run CLI command.
- Inspect config for `storyboard_director_sonnet5`.
- Confirm no secrets printed in logs/reports.

## Done definition

Done only when Sonnet 5 profile enforcement is implemented, tested, and no-fallback behavior is proven.
