# S22_T021 - Add regression fixtures for known failures

## Objective

Add regression fixtures covering the known storyboard and production failures so the system cannot backslide.

## Primary agent

Software Engineer

## Supporting agents

- Software Auditor
- Software Validator
- Claim Compliance Auditor
- Overlay Timeline Engineer

## Recommended model

`deepseek-v4-flash`

## Context files to load first

- `S22_TEST_AND_GATE_MATRIX.md`
- `fixtures/bad_runs/`
- `reports/remediation/` if present
- `tests/test_reconcile_storyboard.py`
- `tests/test_compile_media_prompts.py`
- `tests/test_render_graphics.py`
- `tests/test_qa_media.py`

## Likely implementation targets

- `tests/fixtures/storyboard_v2/bad/`
- `tests/fixtures/storyboard_v2/good/`
- `tests/test_storyboard_v2_regressions.py`
- `reports/karpathy_loop/s22/S22_T021/`

## Explicit non-goals

- Do not change production behavior except where existing validators are invoked by tests.
- Do not add large media files unless existing tiny deterministic fixtures are insufficient.
- Do not run paid APIs.

## Required behavior

Add fixtures for:

- all-hero storyboard
- generic B-roll
- missing `shot_type`
- missing `asset_type`
- `graphic` vs `graphics` mismatch
- unsupported claim
- irrelevant graphic
- missing segment work order
- missing timing drift policy
- long actual duration requiring trim
- short actual duration requiring block
- stale artifact reuse attempt
- raw `visual_brief` poison prompt

## Detailed tests

Required tests:

1. All bad fixtures fail at the correct gate.
2. At least one good semantic storyboard fixture passes all pre-spend gates.
3. Poison `visual_brief` never appears in media plan.
4. Duration drift fixtures route to trim/pad/block as expected.
5. Feedback fixtures produce targeted change requests.
6. Stale artifact fixture is rejected.

Required commands:

```bash
python3 -m pytest tests/test_storyboard_v2_regressions.py -q
python3 -m pytest tests/test_compile_media_from_canonical_shots.py tests/test_duration_drift_resolver.py -q
```

## Pass gates

- Known failures are durable fixtures.
- Each fixture maps to a named failure reason.
- Good fixture proves the gate is not impossible to pass.

## Audit checklist

- Confirm fixture failures are meaningful, not file-existence checks.
- Confirm bad fixtures cover the historical failure classes.
- Confirm no large/generated media was committed.

## Validation checklist

- Run regression tests.
- Inspect fixture list.
- Confirm report enumerates every fixture and expected gate.

## Done definition

Done when the historical storyboard failure modes are pinned by automated regression tests.
