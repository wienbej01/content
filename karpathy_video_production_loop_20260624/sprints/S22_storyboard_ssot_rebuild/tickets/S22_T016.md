## Required behavior

Assembly must support:

- overlay artifact paths
- start/end times
- layers/render order
- 16:9 and 9:16 safe-zone variants
- multiple overlays per shot
- overlays on top of B-roll or hero without becoming standalone segments

## Detailed tests

Required tests:

1. Overlay renders deterministic local artifact.
2. 16:9 overlay appears only in expected time window.
3. 9:16 overlay appears only in expected time window.
4. Multiple overlays respect layer order.
5. Overlay outside video duration fails.
6. Missing overlay artifact blocks assembly.
7. Existing assembly without overlays still passes.

Required commands:

```bash
python3 -m pytest tests/test_assembly_overlay_timeline.py tests/test_render_graphics.py -q
python3 -m pytest tests/test_assemble_lb202.py -q
```

## Pass gates

- Overlay timing is verifiable.
- Existing no-overlay assembly remains compatible.
- Rendered overlays are deterministic local artifacts.

## Audit checklist

- Confirm no card-inside-card or generic graphic fallback is introduced.
- Confirm safe-zone variants are handled.
- Confirm assembly failure is explicit if overlay missing.

## Validation checklist

Done when overlay plans can be rendered and assembled deterministically.
