# S22_T011 - Add Sonnet creative review gate

## Objective

Add a creative review gate that uses Sonnet 5 to review a Python-valid storyboard for visual argument quality, B-roll specificity, graphics relevance, retention rhythm, and conclusion alignment.

## Primary agent

Prompt Guardrail Engineer

## Supporting agents

- Visual Director
- Software Engineer
- Software Auditor
- Software Validator

## Recommended model

`deepseek-v4-flash`

## Context files to load first

- `S22_PROMPT_GUARDRAILS.md`
- `docs/reviewer_prompts/visual_director.md`
- `docs/reviewer_prompts/filmmaker.md`
- `docs/reviewer_prompts/audience.md`
- `docs/reviewer_prompts/technical.md`
- `scripts/review.py`
- `scripts/review_storyboard.py`

## Likely implementation targets

- `scripts/review_storyboard_v2.py` or extension of existing reviewer path
- `docs/prompts/STORYBOARD_SONNET5_CREATIVE_REVIEW.md`
- `tests/test_storyboard_creative_review_gate.py`
- `reports/karpathy_loop/s22/S22_T011/`

## Explicit non-goals

- Do not let review override Python validation.
- Do not implement human approval.
- Do not repair storyboards in this ticket.
- Do not call live Sonnet in default tests.

## Required behavior

Review gate must:

- Require Python validation pass first.
- Use Sonnet 5 profile.
- Score narrative alignment, B-roll specificity, graphics relevance, evidence use, retention rhythm, conclusion support, and production feasibility.
- Return structured JSON with `status`, `may_proceed`, `blocking_issues`, `warnings`, and `recommended_fixes`.
- Fail if reviewer output is malformed.
- Fail if model profile is not Sonnet 5.

## Detailed tests

Required tests:

1. Valid storyboard plus passing stub review passes.
2. Python-invalid storyboard cannot be reviewed as pass.
3. Generic B-roll fixture gets failing review.
4. Irrelevant graphic fixture gets failing review.
5. Weak conclusion alignment gets failing review.
6. Malformed review JSON fails.
7. Non-Sonnet profile fails.
8. Review output includes actionable affected entity IDs.

Required commands:

```bash
python3 -m pytest tests/test_storyboard_creative_review_gate.py -q
python3 -m pytest tests/test_reviewers.py -q
```

## Pass gates

- Creative review is Sonnet-only.
- Python validation remains the hard precondition.
- Review failures are routed to repair or blocking report.

## Audit checklist

- Confirm review gate cannot approve invalid schema.
- Confirm review prompt checks conclusion and references.
- Confirm output schema is enforced.

## Validation checklist

- Run focused tests.
- Inspect sample review output.
- Confirm no live model call.

## Done definition

Done when creative review is a structured, Sonnet-only gate after Python validation.
