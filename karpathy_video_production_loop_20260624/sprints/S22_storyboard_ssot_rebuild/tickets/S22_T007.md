# S22_T007 - Add segment work-order validator

## Objective

Validate that every approved script segment receives clear, actionable storyboard instructions for shots, B-roll, graphics, overlays, QA, and conclusion alignment.

## Primary agent

Software Engineer

## Supporting agents

- Visual Director
- Software Auditor
- Software Validator

## Recommended model

`deepseek-v4-flash`

## Context files to load first

- `S22_PROMPT_GUARDRAILS.md`
- `S22_STRUCTURAL_FRAMEWORK.md`
- `schemas/storyboard_v2.schema.json`
- `scripts/review_storyboard.py`
- `tests/test_direct_storyboard.py`

## Likely implementation targets

- `scripts/validate_storyboard_v2.py` or existing storyboard validation module
- `tests/test_segment_work_orders.py`
- `tests/fixtures/storyboard_v2/`
- `reports/karpathy_loop/s22/S22_T007/`

## Explicit non-goals

- Do not call Sonnet.
- Do not repair invalid work orders.
- Do not modify compiler or DB.

## Required behavior

Validator must require one work order per approved script segment. Each must include:

- exact narration text
- argument summary
- viewer question
- retention role
- shot refs
- overlay refs or explicit no-overlay reason
- B-roll alignment instruction
- graphic alignment instruction
- conclusion alignment instruction when segment participates in setup/payoff/conclusion
- QA acceptance criteria
- must-avoid list

## Detailed tests

Required tests:

1. Complete work orders pass.
2. Missing segment work order fails.
3. Work order with narration text mismatch fails.
4. Missing B-roll instruction for B-roll segment fails.
5. Missing graphic instruction for graphic overlay fails.
6. Empty QA criteria fails.
7. Work order references unknown shot fails.
8. Work order references unknown overlay fails.
9. Conclusion segment with no conclusion alignment fails.

Required commands:

```bash
python3 -m pytest tests/test_segment_work_orders.py -q
```

## Pass gates

- Validator catches missing or vague work orders.
- Error messages identify segment IDs.
- No LLM calls are needed.

## Audit checklist

- Confirm validator enforces exact segment coverage.
- Confirm tests include old bad behavior.
- Confirm failure messages are actionable.

## Validation checklist

- Run focused tests.
- Inspect invalid fixture output.
- Confirm report files exist.

## Done definition

Done when segment work orders are enforceable and every segment can be audited before spend.
