# S22_T008 - Add semantic alignment validator

## Objective

Block storyboards where B-roll, graphics, overlays, or conclusion visuals are generic, irrelevant, unsupported, or disconnected from the script argument.

## Primary agent

Storyboard Architect

## Supporting agents

- Claim Compliance Auditor
- Visual Director
- Software Engineer

## Explicit non-goals

- Do not add LLM creative review.
- Do not implement repair.
- Do not alter media generation.

## Required behavior

Validator must block:

- generic B-roll phrases
- B-roll missing `narrative_alignment`
- B-roll alignment that does not mention the segment argument/claim/viewer takeaway
- overlays missing `semantic_purpose`
- overlays with source labels but no source/claim ref
- graphics that decorate without explaining
- final/conclusion beats that introduce unrelated visuals
- generated-video shots requesting readable text

## Detailed tests

Required tests:

1. Specific source-grounded B-roll passes.
2. "business people in office" fails as `BLOCKED_GENERIC_BROLL`.
3. B-roll with vague alignment fails.
4. Overlay without semantic purpose fails.
5. Statistic overlay without claim ref fails.
6. Graphic unrelated to segment argument fails.
7. Conclusion beat with unrelated visual fails.
8. Emotional reset generic visual passes only with explicit `visual_role=emotional_reset` and justification.
9. Readable text inside generated video fails.

Required commands:

```bash
python3 -m pytest tests/test_storyboard_semantic_alignment.py -q
python3 -m pytest tests/test_broll_semantic.py tests/test_semantic_role_pipeline.py -q
```

## Pass gates

- Old generic storyboard patterns fail loudly.
- All failures point to entity ID and field.
- No Python creative replacement is produced.

## Audit checklist

- Confirm validator blocks common generic phrases.
- Confirm conclusion alignment is checked.
- Confirm claim refs are checked for evidence visuals.

## Validation checklist

- Run focused and related tests.
- Inspect failure JSON.
- Confirm no repair or generation side effects.

## Done definition

Done when semantic alignment is a hard pre-spend gate.
