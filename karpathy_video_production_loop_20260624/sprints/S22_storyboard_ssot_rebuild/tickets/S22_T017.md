# S22_T017 - Record observed artifact durations

## Objective

After media or overlay artifacts are created or registered, record their probed observed duration in the DB so drift from planned duration is explicit.

## Primary agent

DB Feedback Engineer

## Supporting agents

- Software Engineer
- Software Auditor
- Software Validator

## Recommended model

`deepseek-v4-pro`

## Explicit non-goals

- Do not resolve drift.
- Do not regenerate media.
- Do not add new DB tables unless existing columns are insufficient.

## Required behavior

When a video/graphic artifact is registered or QA-probed:

- Probe actual duration with ffprobe or existing helper.
- Store duration on `artifacts.duration_ms`.
- Store duration on `render_units.actual_render_duration_ms` when linked to a render unit.
- Preserve `render_units.required_duration_ms`.
- Record evidence with artifact id, render unit id, required duration, actual duration, and delta.

## Detailed tests

Required tests:

1. Registering 5.1s fixture artifact records `artifacts.duration_ms`.
2. Linked render unit records `actual_render_duration_ms`.
3. Required duration remains unchanged.
4. Missing/corrupt artifact fails with explicit probe error.
5. Non-video local graphic duration is handled according to existing renderer metadata or fails clearly.
6. Re-registering same artifact remains idempotent.
7. Duration evidence is included in validation/report output.

Required commands:

```bash
python3 -m pytest tests/test_observed_artifact_duration.py -q
python3 -m pytest tests/e2e/test_crash_matrix.py -q
```

## Pass gates

- Observed duration is persisted.
- Planned and actual durations are distinct.
- No drift decision is made yet.
- Artifact registration stays idempotent.

## Audit checklist

- Confirm existing DB columns are used before proposing migration.
- Confirm ffprobe failures do not silently pass.
- Confirm no media provider is called.

## Validation checklist

- Run focused tests.
- Inspect DB rows from test evidence.

## Done definition

Done when observed media duration is reliable DB truth for later drift resolution.
