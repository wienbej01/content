## Explicit non-goals

- Do not call Sonnet live.
- Do not implement wrapper code.
- Do not change storyboard schema.
- Do not implement repair loop.

## Required behavior

Prompt files must specify:

- Sonnet 5 is the storyboard author.
- Approved script cannot be changed.
- Output must be raw JSON matching schema.
- Every segment must have work orders.
- Every B-roll shot must be specific, argued, and source/conclusion aligned.
- Every graphic/overlay must explain a point, not decorate.
- Every claim visual must cite claim/source refs.
- Every shot must contain timing drift and assembly fit policy.
- Every repair must be targeted and narration-safe.

## Detailed tests

Required tests:

1. Prompt contains immutable narration rule.
2. Prompt contains strict JSON rule.
3. Prompt contains Sonnet 5 authority language.
4. Prompt requires `segment_work_orders`.
5. Prompt requires `why_this_visual`, `narrative_alignment`, and `semantic_purpose`.
6. Prompt bans generic B-roll terms.
7. Prompt requires conclusion-alignment instruction.
8. Prompt requires duration drift policy.
9. Repair prompt forbids unrelated rewrites.
10. Creative review prompt cannot approve Python-authored storyboards.

Required commands:

```bash
python3 -m pytest tests/test_storyboard_prompt_packet.py -q
rg -n "approved script is immutable|segment_work_orders|duration_drift_policy|generic" docs/prompts/STORYBOARD_SONNET5_*.md
```

## Pass gates

- Prompts are explicit enough for a lesser model to implement wrapper/validators later.
- Prompt tests prove required guardrail text exists.
- No prompt asks Sonnet to rewrite narration.
- No prompt delegates readable text to generated video.

## Audit checklist

- Confirm prompt includes all required context inputs.
- Confirm prompt distinguishes canonical storyboard from compatibility projection.
- Confirm prompt has clear repair constraints.

## Validation checklist

- Run prompt tests.
- Inspect prompts manually for ambiguous authority/fallback language.
- Confirm no live LLM call was made.

## Done definition

Done only when prompt packet and tests make Sonnet-authored storyboard generation robust and constrained.
