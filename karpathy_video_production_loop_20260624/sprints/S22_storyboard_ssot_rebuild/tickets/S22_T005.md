# S22_T005 - Add claim inventory schema and validator plan

## Objective

Create the claim inventory contract and validation plan so storyboard shots and overlays can reference factual claims without inventing unsupported evidence.

- Do not implement live source research.
- Do not call LLMs.

- Do not change storyboard generation.

## Required behavior

Claim inventory must support:

- `claim_id`
- `source_id`
- `claim_text`
- `claim_type`
- `citation_status`
- `requires_visual_reinforcement`
- `allowed_visual_treatment`
- `script_segment_refs`
- `storyboard_entity_refs`

Validator plan must require:

- source-backed factual/stat/study/person/date claims
- unsupported claims marked `opinion` or `original_argument`
- overlays with source labels reference valid claims
- graphics that show statistics reference valid claims

## Detailed tests

Required tests:

1. Valid source-backed claim passes.
2. Statistic without source fails.
3. Study/person/date claim without source fails.
4. Opinion claim without source passes only if explicitly typed `opinion`.
5. Overlay source ref to unknown claim fails.
6. Duplicate claim IDs fail.
7. Unsupported visual treatment fails.
8. Claim linked to nonexistent segment fails.

Required commands:

```bash
python3 -m pytest tests/test_claim_inventory_schema.py -q
```

## Pass gates

- Claim schema exists.
- Negative fixtures prove unsupported claims fail.
- Contract doc explains how Sonnet should link claims to visuals.
- No live research or LLM calls are introduced.

## Audit checklist

- Verify source-backed vs opinion handling.
- Verify claim refs are stable IDs, not prose matching.
- Verify fixtures are realistic.

## Validation checklist

- Run focused tests.
- Confirm reports include fixture paths and command output.

## Done definition

Done when claim inventory can be validated independently and is ready to integrate into storyboard schema/wrapper.
