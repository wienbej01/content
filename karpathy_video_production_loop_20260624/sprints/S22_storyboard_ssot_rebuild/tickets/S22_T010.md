# S22_T010 - Add bounded Sonnet repair loop

## Objective

Implement a targeted repair loop where validation failures are sent back to Sonnet 5 for minimal storyboard repair, without narration changes or unrelated rewrites.

## Primary agent

Prompt Guardrail Engineer

## Supporting agents

- Storyboard Architect
- Software Engineer
- Software Auditor
- Software Validator

## Recommended model

`deepseek-v4-pro`

- `S22_PROMPT_GUARDRAILS.md`
- `S22_MODEL_ROUTING.md`
- `scripts/repair_storyboard_beats.py`
- `scripts/llm_call.py`
- `scripts/direct_storyboard.py`
- `tests/test_reconcile_storyboard.py`

## Likely implementation targets

- `scripts/repair_storyboard_v2.py` or existing repair module
- `docs/prompts/STORYBOARD_SONNET5_REPAIR.md`
- `tests/test_storyboard_sonnet_repair_loop.py`
- `reports/karpathy_loop/s22/S22_T010/`

## Explicit non-goals

- Do not create Python creative repairs.
- Do not repair media artifacts.
- Do not implement compliance feedback ingestion.
- Do not run live Sonnet in tests.

## Required behavior

Repair loop must:

- Accept canonical storyboard, validation errors, and affected entity IDs.
- Send only affected entities plus necessary adjacent context.
- Use `storyboard_director_sonnet5`.
- Preserve approved narration exactly.
- Preserve unaffected entity IDs and content.
- Cap attempts, default 2.
- Write repair log with changed fields.
- Fail with `BLOCKED_REPAIR_EXHAUSTED` if still invalid.

## Detailed tests

Required tests:

1. Stub repair fixes missing `semantic_purpose`.
2. Stub repair fixes generic B-roll alignment.
3. Repair attempt that changes narration fails.
4. Repair attempt that rewrites unaffected segment fails.
5. Repair using non-Sonnet profile fails.
6. Invalid repair after max attempts fails `BLOCKED_REPAIR_EXHAUSTED`.
7. Repair log includes affected IDs and changed fields.
8. Dry-run produces prompt without invoking Kilo.

Required commands:

```bash
python3 -m pytest tests/test_storyboard_sonnet_repair_loop.py -q
python3 -m pytest tests/test_llm_call.py -q
```

## Pass gates

- Repair loop is bounded.
- No Python creative fallback exists.
- Narration immutability is tested.
- Repair output is revalidated.

## Audit checklist

- Inspect repair prompt payload for scope minimization.
- Confirm no unrelated rewrite path.
- Confirm errors are named and actionable.

## Validation checklist

- Run focused tests.
- Inspect repair logs.
- Confirm no live Kilo call in default tests.

## Done definition

Done when targeted Sonnet repair is constrained, testable, and fail-closed.
