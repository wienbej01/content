# S22_T003 - Define LLM-authored storyboard schema

## Objective

Extend the storyboard contract so Sonnet 5 can author a canonical storyboard containing claims, narrative beats, shots, overlays, segment work orders, timing policy, and feedback policy.

Storyboard Architect

## Required behavior

Schema must require:

- `storyboard_contract_version`
- `approved_script_revision_id`
- `approved_script_sha256`
- `authoring_model_profile`
- `authoring_model`
- `claim_inventory[]`
- `narrative_beats[]`
- `shots[]`
- `overlays[]`
- `segment_work_orders[]`
- `feedback_policy`
- `timing_policy`
- `approval`

Each segment work order must include:

- exact narration text
- argument summary
- viewer question
- retention role
- B-roll alignment instruction
- graphic alignment instruction
- conclusion alignment instruction
- QA acceptance criteria

Each shot must include:

- `why_this_visual`
- `narrative_alignment`
- `planned_duration_sec`
- `min_usable_duration_sec`
- `max_usable_duration_sec`
- `duration_drift_policy`
- `assembly_fit_policy`

Each overlay must include:

- `semantic_purpose`
- timing offsets
- safe-zone data
- style token
- source/claim refs where applicable

## Detailed tests

Required tests:

1. Valid semantic storyboard fixture passes schema.
2. Missing `segment_work_orders` fails.
3. Shot missing `why_this_visual` fails.
4. B-roll shot missing `narrative_alignment` fails.
5. Overlay missing `semantic_purpose` fails.
6. Shot missing drift policy fails.
7. Storyboard missing model profile fails.
8. Storyboard using non-Sonnet author profile fails schema or validation helper.
9. Approved script hash missing fails.
10. Existing legacy fixture is either rejected or explicitly routed through compatibility mode.

Required commands:

```bash
python3 -m pytest tests/test_storyboard_v2_schema.py -q
python3 -m pytest tests/test_direct_storyboard.py tests/test_reconcile_storyboard.py -q
```

## Pass gates

- Schema is documented.
- Positive and negative fixtures exist.
- Existing schema consumers are not broken without an intentional compatibility path.
- No Python creative generation is introduced.

## Audit checklist

- Confirm schema enforces semantic fields and timing policy.
- Confirm legacy compatibility is explicit.
- Confirm schema does not make generated prompt text the SSOT.

## Validation checklist

- Run focused schema tests.
- Inspect fixtures.
- Confirm reports include all failures and pass evidence.

## Done definition

Done only when the canonical semantic storyboard contract is schema-testable and documented.
