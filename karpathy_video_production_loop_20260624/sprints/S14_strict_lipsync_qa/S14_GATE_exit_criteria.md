# S14 Exit Criteria

The sprint may close only when every sprint success criterion is satisfied:

- [ ] Close hero fail threshold <=45ms.
- [ ] Medium hero fail threshold <=60ms.
- [ ] 2-frame offset is not publish-pass for close hero.
- [ ] SyncNet confidence affects pass/fail.
- [ ] Per-hero evidence required; merged face track insufficient.

## Required reports

- Each ticket has engineering/audit/validation reports.
- Sprint summary exists.
- Loop state updated.
- No unresolved BLOCKER/MAJOR items.

## Exit decision

The Steering Committee must write:

`reports/karpathy_loop/s14/sprint_summary.md`

with:

- PASS/FAIL/BLOCKED
- evidence paths
- tests run
- known residual risks
- next sprint readiness
