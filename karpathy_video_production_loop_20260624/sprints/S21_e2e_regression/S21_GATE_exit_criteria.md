# S21 Exit Criteria

The sprint may close only when every sprint success criterion is satisfied:

- [ ] Research/script/beat contract/render/QA/assembly/package run end to end.
- [ ] Output satisfies 2 hero + 1 broll + 1 graphic.
- [ ] Hero sync passes strict thresholds.
- [ ] Graphic template-rendered and aligned.
- [ ] B-roll semantically verified.
- [ ] Publish output 1920x1080 or explicitly test-local.
- [ ] Gate B package truthful.

## Required reports

- Each ticket has engineering/audit/validation reports.
- Sprint summary exists.
- Loop state updated.
- No unresolved BLOCKER/MAJOR items.

## Exit decision

The Steering Committee must write:

`reports/karpathy_loop/s21/sprint_summary.md`

with:

- PASS/FAIL/BLOCKED
- evidence paths
- tests run
- known residual risks
- next sprint readiness
