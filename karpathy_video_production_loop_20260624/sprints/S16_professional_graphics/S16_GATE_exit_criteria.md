# S16 Exit Criteria

The sprint may close only when every sprint success criterion is satisfied:

- [ ] Local graphics use named templates.
- [ ] No black title-card default.
- [ ] Graphics semantically tied to beat.
- [ ] Readable at mobile size.
- [ ] Graphics animate/reveal if >2s.
- [ ] Graphic QA blocks ugly/empty/misaligned assets.

## Required reports

- Each ticket has engineering/audit/validation reports.
- Sprint summary exists.
- Loop state updated.
- No unresolved BLOCKER/MAJOR items.

## Exit decision

The Steering Committee must write:

`reports/karpathy_loop/s16/sprint_summary.md`

with:

- PASS/FAIL/BLOCKED
- evidence paths
- tests run
- known residual risks
- next sprint readiness
