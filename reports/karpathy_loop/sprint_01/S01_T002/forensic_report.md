## How comparison works (numpy-based)
1. Load source slice WAV + provider diagnostic WAV → numpy arrays
2. Compute duration of each (seconds, from samples)
3. Compute cross-correlation to find estimated offset
4. Normalize correlation for confidence metric
5. Compare: pass if duration delta < threshold AND offset < threshold
